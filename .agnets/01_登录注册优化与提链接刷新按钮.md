# 注册助手浏览器插件调整方案

本文档汇总了本次对话中针对 ChatGPT 注册及提链接助手（`openai-plus-vxt`）进行的一系列功能调整和界面优化。

---

## 调整背景与需求

1. **多网页导航条留存**：原插件仅在 `chatgpt.com` / `openai.com` 等特定域名下显示，当用户在其他页面时无法看见面板。需将面板改为全局显示。
2. **快捷引导与状态标识**：提供对“登录/注册”页面的直接链接，且当用户处于对应页面时，在面板上进行高亮显示，指引其快速前往。
3. **JP/US 区域标识**：为了防止操作混淆，需要为四大主要 Tab 标签增加明确的区域标识（JP/US）。
4. **面板宽度拓宽**：为了适应更长的 Tab 标题并提升可读性，将面板从 320px 进一步拓宽至 380px，并微调 Tab 布局。
5. **提链接默认值修改**：为了符合常用习惯，将“提链接”的默认链接形式从“短链接/custom”改为“长链接/hosted”。
6. **提链接“刷新”功能集成**：在“生成订阅链接”左侧新增一个“刷新”按钮，用于手动拉取 Session，并支持 1:3 的自适应列宽比例。

---

## 具体修改内容及文件清单

### 1. 全局域名匹配（面板跨站可用）
* **修改文件**：[`entrypoints/content.ts`](file:///d:/02_ben_work/02_ai/01_openai/openai-plus-vxt/entrypoints/content.ts)
* **实现逻辑**：将 Content Script 的 `matches` 规则由具体的 OpenAI 域名变更为 `http://*/*` 和 `https://*/*`，确保用户在任何网站上均可使用该面板来进行跨国地址获取、接码和提链接等操作。

### 2. 界面宽度拓宽与自适应标签栏
* **修改文件**：[`src/app/styles.ts`](file:///d:/02_ben_work/02_ai/01_openai/openai-plus-vxt/src/app/styles.ts)
* **实现逻辑**：
  * 将 `.opx-panel` 的宽度定义从 `min(320px, ...)` 调整为 `min(380px, calc(100vw - 42px))`。
  * 将 `.opx-tabs` 的 `display: grid` 改为 `display: flex; gap: 2px`，配合 `.opx-tab` 的 `flex: auto` 和更小的字号（`11px`），在 380px 宽度下完美容纳带 JP/US 后缀的四个 Tab。

### 3. JP/US 区域标识与 Tab 标签修改
* **修改文件**：[`src/app/panel.ts`](file:///d:/02_ben_work/02_ai/01_openai/openai-plus-vxt/src/app/panel.ts)
* **实现逻辑**：将 Tab 按钮标签文本进行重置：
  * “注册” $\rightarrow$ **“登录/注册 (JP)”**
  * “提链接” $\rightarrow$ **“提链接 (JP)”**
  * “地址” $\rightarrow$ **“地址 (US)”**
  * “接码” $\rightarrow$ **“接码 (US)”**

### 4. 注册面板增加流程快捷导航与高亮
* **修改文件**：[`src/features/register/panel.ts`](file:///d:/02_ben_work/02_ai/01_openai/openai-plus-vxt/src/features/register/panel.ts)、[`src/features/register/chatgpt-auth-page.ts`](file:///d:/02_ben_work/02_ai/01_openai/openai-plus-vxt/src/features/register/chatgpt-auth-page.ts)、[`src/app/styles.ts`](file:///d:/02_ben_work/02_ai/01_openai/openai-plus-vxt/src/app/styles.ts)
* **实现逻辑**：
  * 在“登录/注册”面板最上方新增 `opx-guide-box` 引导区。
  * 内嵌指向 `https://chatgpt.com/auth/login` 的 **“登录/注册”** 快速导航超链接。
  * 在 `update()` 轮询中根据当前 `location.hostname` 匹配，在对应网页下自动为导航项添加 `.is-active` 激活样式并在右侧显示一个小圆点 `●`。
  * 改进了 `isChatGptLoginPage` 识别逻辑，不仅匹配 `/auth/login` 路径，当检测到页面上有符合特征的 Email 输入框时也判定为登录页面，自动激活。

### 5. 提链接默认链接形式设为“长链接”
* **修改文件**：[`src/features/link-extractor/checkout.ts`](file:///d:/02_ben_work/02_ai/01_openai/openai-plus-vxt/src/features/link-extractor/checkout.ts)、[`src/features/link-extractor/panel.ts`](file:///d:/02_ben_work/02_ai/01_openai/openai-plus-vxt/src/features/link-extractor/panel.ts)
* **实现逻辑**：
  * 修改 `DEFAULT_CHECKOUT_OPTIONS.uiMode` 默认值为 `'hosted'`。
  * 在 `panel.ts` 的 `uiModeSelect` 构建列表中，将 `['hosted', '长链接 / hosted']` 移动 to 首位，从而在初次加载和未设置状态下默认选中“长链接”。

### 6. 在生成订阅链接旁新增 1:3 比例的“刷新”按钮
* **修改文件**：[`src/features/link-extractor/panel.ts`](file:///d:/02_ben_work/02_ai/01_openai/openai-plus-vxt/src/features/link-extractor/panel.ts)、[`src/app/styles.ts`](file:///d:/02_ben_work/02_ai/01_openai/openai-plus-vxt/src/app/styles.ts)
* **实现逻辑**：
  * 声明二等样式按钮 `refreshButton`（文本为“刷新”），与主按钮 `generateLinkButton` 组合进一个 `.opx-grid-1-3` 容器。
  * 在 CSS 中定义 `.opx-grid-1-3 { display: grid; grid-template-columns: minmax(0, 1fr) minmax(0, 3fr); gap: 8px; }`，确保左侧刷新按钮占 1 份空间，右侧生成按钮占 3 份空间。
  * 将刷新按钮的点击事件绑定至 `refreshSession()`，实现读取 `https://chatgpt.com/api/auth/session` 接口并自动提取 Token 到输入框的效果。
  * 在 `refreshSession()` 发起请求期间，同时禁用顶部的“读取 ChatGPT session”按钮和该“刷新”按钮，请求结束后一同恢复。
